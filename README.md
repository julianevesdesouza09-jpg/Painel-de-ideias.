# Painel-de-ideias.

SOBRE O PROJETO

Aplicação web desenvolvida para gerenciar ideias de forma simples e mais rápida.

---

## Funcionalidades

- Adicionar uma nova ideia
- Listar todas as ideias
- Marcar ideia como concluída
- Remover ideia
- Contador de ideias totais e concluídas
- Validação de campo vazio

---

## Tecnologias utilizadas

- React
- JavaScript
- CSS
- Vite
